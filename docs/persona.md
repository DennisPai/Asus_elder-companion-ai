### 1.3 生活描述 Vignette

🟡 基於 §2.2.2 + §2.5 文化面向推導之 desk 假設

冠廷 8:30 進公司 standup，跨時區 Slack 協作。中午外食滑手機看兩條新聞。下午 code + code review 到 18:30，21:00 回家陪孩子洗澡說睡前故事。

每天 22:30-23:00 有 15 分鐘窗口試著 LINE 視訊父母。但父母睡得早，10:30 後接了也心不在焉，偶爾不接。隔天他在公司群組看別人聊「父母健康」話題輕輕按讚，繼續寫 PR。

週末早上稍輕鬆。他偶爾想打電話，怕把父母叫醒，或怕沒話說、三分鐘變成報告式寒暄。上週六媽打來說「爸昨天頭暈，吃飯沒胃口」，他掛掉後在公司群組問「高血壓頭暈要去急診嗎」，有人回「先量血壓超過 160 再去」，他想傳給爸爸但爸爸不太會用手機量血壓。

遠距照顧焦慮源：① 父母不會即時回報異狀 ② 自己不在場，意外可能延誤幾小時才發現 ③ 每週打電話已是最大努力，但仍感覺「萬一一定後悔」④ 配偶偶爾提「那麼多電話費為什麼不請鐘點」⑤ 妹妹和他的責任分配在家庭 LINE 群未明說產生隱性張力

### 1.4 痛點 + 觸發事件

🟡 痛點對應 §1.2 + §3.2，觸發事件 desk 場景推論

**5 個具體痛點**：
1. **S0 緊急盲點**：父母跌倒 / 突發疾病平均延誤 4-12 小時。緊急按鈕需主動按，父母不習慣戴
2. **S1 孤獨焦慮傳染**：每次視訊「吃飯了沒、天氣怎樣」重複迴路。媽說「沒事啦沒什麼好說的」感覺比說出來更重
3. **S2 用藥不確定**：每週問「藥有吃嗎」父母都說有，但無法確認。回家發現藥盒沒動幾顆
4. **S2 設備能力不對等**：智慧型手機教兩個週末，父母只用 LINE 拍照，健康 app 視訊放棄
5. **S3 愧疚感與孝道落差**：同齡同事有的搬回去陪父母，他做不到，「買個好東西」是現在最有能力的具體孝順表達

**2 個過去 12 個月真實觸發事件（desk 推論）**：
- **觸發 A**（去年 12 月）：母親夜間如廁滑倒，早上 7 點才告知「跌一跤膝蓋紅，好了啦」。冠廷下午才知道母親沒去診所只用藥布貼。當晚搜尋「父母在家跌倒偵測」
- **觸發 B**（今年 3 月）：父親忘記打降血糖藥整整 3 天，妹妹回老家看藥盒才發現。家族 LINE 群討論，妹妹說「要不要請個人？」冠廷說「我來想辦法」但沒行動，不知道具體要做什麼

### 2.3 生活描述 Vignette

🟡 基於 §2.2.2b + §2.5 文化面向推導

淑芬 7:30 出門上課，備課 + 教學 + 行政到 4:30，下班開始心理盤算「今天要不要去看一下」。先打電話給母親——不接就焦慮，接了聊 10 分鐘，若父親狀況不穩定母親語氣就沉。

每週三必去，其他天看情況。去了確認藥吃沒、冰箱食物、父親有沒有說奇怪的話（最近兩次把她認成姑姑）。回家 7:30-8:00，晚餐常便利商店。丈夫沒明說抱怨但家庭重心偏移。

週末想帶孩子吃飯，但父親前天說頭不舒服，計畫改成「先去看爸媽再看要不要出門」。最後沒出門，下午在老家坐三小時。

遠距照顧焦慮源：① 父親 MCI 讓「我很好」不可信 ② 沒去而父親發生事，永遠不會原諒自己 ③ 兄長在外地、一人承擔、沒人替換 ④ 不可持續但不知道有什麼工具讓她安心地不每天去 ⑤ 90% 失智家屬長期失眠——每晚入睡前腦海盤點「今天沒做到什麼」

### 2.4 痛點 + 觸發事件

🟡

**5 個具體痛點**：
1. **S1 照顧者身心耗竭**：90% 失智家屬長期失眠 / 65% 異常壓力。生活節奏完全被父母佔據
2. **S0 認知退化盲點**：父親 MCI 讓「他說沒事」不可信。無法判斷「今天沒去」=「真的沒事」還是「有狀況說不清楚」
3. **S2 24/7 待命壓力**：上班時段也無法完全專心，「手機隨時響」的背景焦慮
4. **S2 喘息缺口**：知道「喘息服務」但申請繁複；使用時擔心「別人照顧不熟」；結果還是自己來
5. **S3 兄弟姊妹責任分配不均**：哥哥寄錢但實際照顧全落她身，未被認可。若有客觀記錄可減少情感勞動

**2 個觸發事件（desk 推論）**：
- **觸發 A**（去年 8 月）：父親在家開瓦斯忘關，鄰居聞到打電話。淑芬請假趕去。買了瓦斯感測器但知道只是「點對點」解決
- **觸發 B**（今年寒假）：帶家人去日本 4 天，回程整路焦慮。後來才知父親那幾天沒吃藥「藥盒沒人提醒」。心裡設線：「下次要出門，需要有東西幫我盯著」

### 2.5 既有解法 + 不滿意點

| 既有解法 | 不滿意點 |
|---|---|
| 幾乎每天親自探視 | 不可持續；自己的生活被壓縮 |
| LINE 通話確認 | 父親 MCI 說不清；母親報喜不報憂 |
| 瓦斯 / 煙霧感測器 | 只解決單一風險 |
| 長照 A 級個管師 | 有固定訪視非每天；主要協助正式服務媒合 |
| 喘息服務（政府）| 申請複雜 + 使用時不放心 + 父親對陌生人抗拒 |

### 2.6 WTP + 預算分配

🟡 對齊 §1.5；Persona B 月收偏低，WTP 主落 NT$600-800

| 項目 | 金額 |

## 4. 長者本人視角 Vignette × 3（父母方）

### 4.1 李冠廷父母——秀珍阿嬤 67 歲，南部老家（Persona A 對應）

🟡 健康獨居長者視角（§2.2.1a）

秀珍的一天從 6 點開始。習慣起床先去廟口拜拜，回來煮稀飯，台語電台廣播配早餐。吃完洗碗，坐客廳摺昨天衣服，收音機還在說新聞。

老伴走了三年。她說習慣了，但習慣不代表不覺得靜。電話不常響，LINE 她不太會用，只知道冠廷傳的語音留言按一下聽。昨天他傳了「媽，這幾天天氣冷，你注意一點」。她聽了兩遍，覺得很好。

她最擔心不是病，是「突然出事沒人知道」。電視看過一個老阿伯跌倒在家三天才被發現，那畫面讓她想很久。她不想給冠廷添麻煩，但也知道一個人應付不來。

她對「機器」看法複雜。家裡有冠廷買的 iPad，她只會按最上面 LINE 圖示。其他怕按壞。如果有東西主動跟她說話——而且是台語——她心裡有一點想試。最近隔壁王阿姨兒子買了「會說話的東西」，王阿姨說「有時候沒事跟它說說話比打給兒子方便」。秀珍記在心裡。

她希望陪伴她的東西「我可以跟它說台語、我可以叫它停、它不會亂說話讓我嚇到、也不會把我說的話傳給冠廷讓他擔心」。她要的是陪伴，不是監視。

### 4.2 林淑芬父親——林德仁阿公 76 歲，台中老家（Persona B 對應）

🟡 MCI 長者視角（§2.2.1b）

德仁最近有點搞不清楚。今天幾號？早上吃飯了沒？想了一會兒，有點，也不確定。他知道有時候在想事情，那個想法像霧裡的東西，看得到輪廓，伸手就消失。

他不喜歡讓淑芬看到他不記得事情。她一臉擔心的表情讓他不舒服，他寧願說「我很好」。他以前是工廠師傅，一輩子不麻煩別人。現在年紀大了說不出話也手腳不俐落，但「不要成為負擔」的骨氣還在。

他喜歡廣播、老歌，喜歡坐院子等天黑再進去。老伴說話他聽不太進去，她重複一樣的話。但如果有東西每天問他「德仁，今天有沒有出去走走？」——有人記得他、關心日常的感覺，他覺得可能還可以。

他對「機器」有保留，覺得「壞了怎辦，我弄壞了怎辦」。但台語他懂，如果說台語，「德仁兄，今仔日天氣真好」，他可能回應。不需要它很聰明，只要「有人在那裡」。

他最希望這東西「幫他記住一些事」，不是替他記，是提醒。不想忘，只是有時候需要被提醒——吃藥、幾點、星期幾。讓他維持那一點自主和尊嚴。

### 4.3 陳國華父親——陳義雄阿公 82 歲，台北老公寓（Persona C 對應）

🟡 認知退化中度 + 外籍看護長者視角（§2.2.1b-c 混合）

義雄有時候清楚有時候不清楚。今天早上阿美幫他穿衣，他問「你是誰」，阿美說「是你的阿美啊，阿公」，他點點頭但不是真認出，只是順著節奏。

他喜歡家裡有聲音。電視開著就看，沒看也開著，聲音讓他不是一個人。老伴走了，他知道，但有時候忘了，起床找一圈又想起來，那一刻不想讓任何人看到他的臉。

阿美很好但有些話說不出來——說了她也聽不懂。他想說昨天做了一個夢，夢到他年輕時的摩托車和朋友騎車。這夢想和人說，但說不了。

他對新東西有點害怕。如果有東西坐在旁邊用台語說「阿公，你今天好嗎」，他願意試試。不需要它給答案，需要它等他說話。他說話有時慢、有時接不下去，需要它等——不催、不打斷、不換話題。

他最希望有個東西知道他喜歡什麼。知道他喜歡台語老歌、知道他以前做什麼、知道家裡照片那些人是誰。然後偶爾問他。讓他覺得人生被記得。這比任何「安全偵測」都重要。

**需求 3：主動發起對話（長者不需要主動開口）**
- A：父母等子女打電話，但子女忙；AI 每天主動問候 = 解決「父母孤單但不想麻煩子女」
- B：父親 MCI 不會主動找刺激，需外部主動啟動
- C：父親失智中度，自主啟動困難；阿美語言溝通有限
- 長者端：三位均有「不想成為負擔 + 希望有人在」的文化心理（§2.5 面向 3）；主動問候讓他們「被記得」
- **Phase 3 對應**：ROE 混合架構；每日固定時段問候 + 節慶 / 節氣 / 個人偏好話題；對應 §4.2 ElliQ 差異化抄法
- 🟡 需驗證台灣長者對主動 AI 問候的接受度（vs「嘮叨感」風險）

**需求 4：台語 / 中文對話支援（非英文 only）**
- A：父母台語為主，「怕機器聽不懂台語」是採購顧慮
- B：父親台語母語，MCI 後更易退回台語；國語理解下滑
- C：義雄阿公台語最自然；阿美印尼腔中文，台語對話空缺
- 長者端：三位 vignette 都提台語；「說台語的 AI」在長者端是接受度關鍵開關
- **Phase 3 對應**：MVP 階段基礎台語語音識別 + 台語問候 / 常用詞；完整台語 LLM 對話為 Year 2 里程碑；護城河「台語語料庫」
- 🟡 台語 fine-tune 技術可行性弱（缺大規模訓練資料）；MVP 先做基礎不宣稱完整

**需求 5：長者主動控制感（可以說「不要」「停下來」）**
- A：父母抗拒「被監視」；無關掉選項則退訂（§2.2.3 sub-role 3）
- B：父親「不想成為負擔、不想被管理」——覺得被監控則抗拒固化
- C：秀英本人有隱私顧慮；父母抗拒則 C 也不強迫
- 長者端：秀珍「我可以叫它停、不會亂說話傳給兒子」；義雄需要「等他說話、不打斷」
- **Phase 3 對應**：「長者控制優先」原則（§3.2.4 mitigation）；AI 必遵「停止提醒」24 小時；監控功能預設關閉；UX 強調「我的機器人、我說的算」；對應 §6.3 Frame 關鍵詞「不被監視」
- 🟡 需測試長者實際使用中是否行使此控制

**需求 6：30 分鐘內完成子女遠端設定（不需現場）**
- A：北漂無法飛回去設定；需到場 = 阻斷購買轉化
- B：可到場但時間有限；設定複雜不主動嘗試
- C：付了月費，期望順暢；設定麻煩 = 第一印象差 = NPS 風險
- 長者端：三位均無法自行設定；需子女完成 onboarding 再讓長者「開始用」
- **Phase 3 對應**：「子女 B2C onboarding ≤10 分鐘、不需現場」hard constraint（§2.6 補充 2）；引導 ≤5 步；父母端「叫名字就好」；對應 §1.5 競品 GrandPad「0 設定門檻」抄法

### 5.2 共通需求優先序建議（Kano × 三 Persona 頻度交叉）

### 5.3 MVP Must-have 雛形 → Phase 3 Feature Triage 輸入

基於 5.1 + 5.2，MVP Must-have 最小功能集建議：

1. 中文語音對話（基礎流利；台語問候 + 常用語優先）
2. 每日定時主動問候（長者端）
3. 異常偵測 + LINE 推播子女（非影像，聲音 + 互動中斷為基礎）
4. 子女 App — 每日 / 每週摘要（AI 整理，非原始對話）
5. 長者「停止 / 暫停」指令 + 監控預設關閉
6. 子女遠端 onboarding ≤10 分鐘（引導 App）

以上 6 項在三個 persona 中均有明確需求對應，且長者端 vignette 有支撐。這是 Phase 3 Feature Triage MoSCoW Must-have 的最小可信假設集。後續 Phase 3 需以 Kano 模型驗證（「有它 / 沒它各如何」），配合 WTP 量測決定最終優先序。🟡
