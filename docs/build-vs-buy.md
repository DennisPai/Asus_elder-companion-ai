## 0. Executive Summary

本報告對「長者互動陪伴機器人 × AI Brain」MVP 三大層次（硬體 / AI Brain / 通路）進行 Build vs Buy 決策分析，涵蓋 90 天落地路徑 + Year 1-3 演進，並整合 4 個商業假設（A B2C / B B2B2C / C 保險 PMPM / D Freemium App）給出最終推薦組合。

**核心結論（三句話版）**：
1. **90 天 MVP 唯一可行組合**：硬體路徑 A（Wizard-of-Oz 平板）× AI Brain 路徑 C（混合架構：商業 LLM 主幹 + rule-based 紅線 + 本地 ASR/TTS）× 通路路徑 D（Freemium App 即時）+ 路徑 A（B2C DTC 同步）—— 最低技術門檻、最快驗證 PMF、零庫存風險、可在 8 週內對主管展示可運作規劃書。
2. **Year 1 主路線**：遷移至硬體路徑 B（台灣 ODM）+ AI Brain 路徑 C 持續（逐步台語 fine-tune 升比例）+ 通路路徑 A+B（DTC 為主 + 機構通路 BD 啟動）。
3. **Year 2-3 演進**：AI Brain 路徑 C 升級（開源 Llama/Qwen fine-tune 比例提升，降低 Vendor lock-in）+ 通路路徑 E（電信捆綁 Year 2）+ 路徑 C（保險 PMPM 談判 Year 3+）。

## 2. Layer 1：硬體 Build vs Buy（4 路徑 × 8 維度）

### 2.0 背景：硬體決策的核心張力

AI 陪伴機器人硬體面臨三重張力：
1. **90 天 vs 長期護城河**：90 天 MVP 要零庫存風險、零認證風險；Year 1+ 要可規模化 BOM 控制 + 供應鏈穩定
2. **成本 vs 體驗**：長者陪伴場景有「存在感」需求（PARO / LOVOT 均確認實體形態優於純螢幕），但硬體 BOM 每元都是變現壓力
3. **認證時程 vs GTM 速度**：BSMI 認證 NT$30-100 萬 + 6-12 月 = 硬體賣前的必要投入；Wizard-of-Oz 平板可完全繞開

✅ 以上來源：competitive-analyst §4.7 + problem-framing.md §4.7 Build vs Buy Implications

### 2.1 路徑定義

| 路徑 | 名稱 | 說明 |
|---|---|---|
| **路徑 A** | Wizard-of-Oz 平板 | 市售 iPad / Android 平板（8-11 吋）+ 桌上型底座 + 外接麥克風陣列（如 ReSpeaker 4-mic）+ 可愛外殼；無自製硬體；純軟體驅動；零庫存風險 |
| **路徑 B** | 台灣 ODM | 委託鴻海 / 廣達 / 仁寶 / 緯創等台灣 ODM 廠商；自有設計、台灣製；全球供應鏈 + TSMC 生態 |

| **路徑 D** | 中國 OEM | 委託深圳 / 東莞等中國 ODM 廠商；BOM 最低但有已知資安疑慮 |

**路徑 C 可行性分析**：
- **當前不可行的三個主要原因**：
  1. ASUS 公開策略明確指向自建 AI Brain + 醫院 B2B（公開聲明多次確認）
  2. Zenbo Jr II 缺乏本案核心差異化特性（台語 / 月費訂閱 / 子女 dashboard / B2C 路徑）
  3. OEM 合作談判週期長（6-18 月）+ IP 依賴風險（孤兒化前例：Jr I QAP 終止）
- **若可行需何契機**：
  1. ASUS 策略轉向（公開宣告尋找 B2C 居家陪伴合作夥伴，而非醫院 B2B）
  2. ASUS 願意為外部客戶開放台語支援 + 月費訂閱改造
  3. 長照 3.0 B2C 補貼市場規模足夠大，促使 ASUS 重新評估居家市場優先級
- 🟡 以上「契機」均為假設，無公開資訊支持

**路徑 C 結論**：基於現行公開資訊，路徑 C 不列入 MVP 或 Year 1 執行選項。若 ASUS 策略出現公開轉向訊號，可在 Year 2 重新評估。
