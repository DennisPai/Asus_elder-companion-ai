### 1.5 倫理保護

#### 三方 Informed Consent（依 problem-framing.md §3.2.1）📋

長者訪談（群組 B）三方同意機制：
1. **長者本人**（口頭 + 書面）：大字 A4 同意書（≥20pt）+ 照服員 / 子女輔助說明；關鍵條目台語 / 國台語口頭複述；長者有權隨時停止 / 撤回
2. **子女**（書面）：確認「代理同意不覆蓋長者意願」；若長者當場不願，子女不得施壓
3. **第三方見證**（照服員 / 社工）：A 級個管 / 社區據點由個管師或社工作見證

**同意書內容**（依 PDPA §7, §8 2025 加嚴版）：
- 蒐集目的：產品研究規劃，不商業推廣
- 蒐集範圍：口語回應轉錄稿（無影像、無全程錄音散佈）
- 使用期限：研究分析 6 個月後匿名化；原始錄音 30 天硬刪
- 撤回權：7 天內可要求銷毀所有個人資料

#### PDPA 合規 📋

| 項目 | 操作 |
|---|---|
| 特種個資（PDPA §6）| 健康狀態（MMSE / 失能等級）屬特種個資；蒐集前須明示書面同意 |
| 資料最小化 | 只收訪談轉錄文字；不收姓名（受訪代號 A-01 至 C-05）；不留聯絡電話 |
| 硬刪機制 | 原始錄音 30 天後硬刪（系統覆寫）；轉錄稿匿名化保留最長 6 個月 |
| 跨境傳輸（§21 2025）| 若用 Otter.ai 美國伺服器須同意書揭露跨境；提供台灣本地替代（Google Speech-to-Text asia-east1）|

#### 退出機制

- 任何時點可停止，無需解釋
- 訪談後 **7 天冷靜期**：可發訊撤回所有回應資料
- 長者特殊保護：若訪談中情緒激動 / 明顯疲憊 / 認知混亂跡象，訪談員**必須主動終止**，通知子女 / 陪同人員

#### 認知狀態評估（群組 B 專屬）

- 前篩階段：子女 / 個管師協助粗估，確認 MMSE ≥18 或 5 分鐘以上連貫對話
- 訪談當天：訪談員 2 分鐘「今天是幾月幾號、現在在哪裡」簡單定向確認
- 若狀態不佳（混亂 / 無法集中 >2 分鐘）：延期或取消，謝禮仍全額發放

#### IRB 考量 🟡

醫院神經科轉介可能需 IRB 審查（4-6 週簡易審查）。建議：
- 優先「社區關懷據點 + A 級個管」管道（可規避 IRB）
- 必須透過診間轉介時，Phase 2 執行前評估是否申請 IRB

## 4. 訪談者培訓計畫 📋

### Day 1-2：Mom Test 紀律
- 三規則：(1) 過去行為非未來假設 (2) 不洩漏 / 引導產品 (3) 具體事件非主觀評價
- 違規問題辨識演練（10 題分辨合規 vs 違規，評分 ≥8/10）
- 本案 8 題訪談大綱熟練（不看稿流利問完）

### Day 3-4：Vulnerable Population 倫理培訓
- 長者 / MCI 訪談特殊要求（語速放慢 20%、複合選項禁止、辨識疲憊 / 混亂信號）
- 三方同意書執行（角色扮演通過）
- 緊急情境 SOP（情緒崩潰 / 身體不適 / 負面情緒過深）

### Day 5：訪談技術 + 工具
- 錄音工具 + 開場固定話術

## 6. 長照訪談 vs 一般市場研究的差異

| 面向 | 一般 UX Research | 長照 / 長者訪談（本案）| 影響 |
|---|---|---|---|
| 知情同意 | 電子同意書 / checkbox | 三方同意（長者 + 子女 + 第三方）+ 書面 + 台語口頭 + 字體 ≥20pt | 增加 15-20 分鐘前置；需紙本 |
| 樣本篩選 | 年齡 / 職業即可 | 加認知狀態評估（MMSE）+ 排除重度失能 | 招募延長 3-5 天 + 機構轉介 |
| 訪談地點 | 辦公室 / 視訊 / 咖啡廳 | 長者需熟悉環境（家 / 社區據點）| 訪談員親赴受訪地 |
| 訪談長度 | 60-90 分鐘 | 長者上限 40 分鐘 | 問題量濃縮 |
| Mom Test 紀律 | 不引導即可 | 額外禁複合選項題 / 技術詞 /「如果您跌倒了」負面假設 | 事前演練長者友善問法 |
| 訪談後追蹤 | 感謝信 + NPS | 若提及孤獨 / 心理困擾，必須通知子女 / 個管 | 訪談員需了解轉介 SOP（1925 / 15480）|
| 資料保護 | PDPA 標準 + 匿名 | 特種個資（§6）+ 30 天硬刪 + 跨境揭露同意 | 不用美國伺服器轉錄而未揭露；備台灣本地替代 |
| 倫理風險 | 不浪費時間 / 不誤導 | 避免情感操控 / 資訊不對稱影響醫療 / 「研究」定位規避消保法 | 腳本「AI 陪伴倫理告知」；不描述產品為「解方」|
| 競品提及 | 「您用過 X 嗎？」 | ASUS Zenbo 相關客觀中立，不影射缺陷、不蒐集貶低資料（華碩主管專業紀律）| 不出現「跟 Zenbo 比哪個好？」引導性比較 |

## Anti-pattern 聲明

本計畫規避以下風險（Steve Blank 4-Step + Mom Test 紀律）：
- 朋友 / 同團隊（confirmation bias）→ ≥30% 必須非自身網絡
- 問卷代替訪談（surveys lie）→ 全採深度個別訪談，問卷只用於前篩
- Leading questions「你會不會用我們的 AI？」→ 8 題大綱 Mom Test 合規
- 訪談人 < 10 → 計畫總目標 17-21 人（A: 8-10 + B: 4-6 + C: 5）
- 認知不足導致無效資料 → §1.5 認知狀態評估機制
