# Elder Companion AI MVP

90 天規劃落地展示「長者互動陪伴機器人 × AI Brain」MVP + 商業模式，最終以 GitHub Page 互動式 dashboard 呈現給公司主管。

## 結構

| 目錄 | 內容 |
|---|---|
| `sop/` | PM 流程 v0.1 SOP + Phase 0.5 題目拆解 framework |
| `openspec/changes/` | OpenSpec change proposals + design + tasks |
| `docs/` | Phase deliverable（phase-0-answers / phase-0.5-deconstruction / interview-log / vpc / lean-canvas / bmc / unit-econ / pitch-deck 等） |
| `research/` | Desk research + 競品 deep dive + 訪談原始紀錄 |
| `web/` | Next.js static export → GitHub Page deploy |

## 流程

採 **PM 視角 90 天 MVP 流程 v0.1**（不走現有 Mode E，待 retrospective 後抽通用部分進 Mode E v6.4）。流程細節見 [sop/pm-flow-v0.1.md](sop/pm-flow-v0.1.md)。

## Deploy

`web/` Next.js static export → `gh-pages` branch → GitHub Pages 自動部署。
